# Brief: Feature 25 — Stage Reality Copy

## Problem

מקור: [discovery 20](../../discovery/20-stage-reality-gaps.md) — בייק חי של אילון,
2026-07-24. שלב 3 מציב רף סיום לא ריאלי ("חלק וגמיש", windowpane) שעם השיטה של
האפליקציה עצמה וקמח ישראלי אף בצק אמיתי לא עומד בו — אופה שבדרך הנכונה חושב
שנכשל. בנוסף: חסר שם אנגלי בשלבים 3 ו-6, הוראת הכיסוי חיה מסך אחד קדימה מהמקום
שבו הספק מתעורר (תפרים 3→4 ו-6→7), ומדידת הנפח של הבאלק מנוסחת בשתי דרכים סותרות.

## Goal

ה-copy של השלבים משקף בצק אמיתי: רף שלב 3 = אחידות (לא חלקוּת), כל שלב שמסתיים
בהמתנה אומר במפורש "כסו ועברו הלאה", שמות אנגליים בשלבים החסרים, ומדידת נפח אחת.

## Scope

### In (אושר מילולית ע"י אילון, 2026-07-24: "תקן את הכל חוץ מהתמונה")
- שלב 3: רף אחידות, ביטול מבחן ה-windowpane (כולל `checkImageUrl` שלו — תמונה של
  קריטריון שבוטל), צעד סיום "סמנו גובה + כסו", `hint: "(final mix)"`.
- שלב 4: נפח נמדד "מהנפח שסימנתם בסוף הלישה" בכל המקומות; שורת "הבצק יחליק אחרי
  2–3 סטים" שסוגרת את הלופ מול שלב 3.
- שלב 6: `hint: "(shaping)"`, צעד אחרון מפנה קדימה לכיסוי+מקרר (תפר 6→7).

### Out
- **החלפת תמונות** (`3-mixed-dough.png`, צילומי אמת) — נדחה במפורש ("את התמונות
  נפתור אחרי זה"). ה-`imageUrl`+`imageAlt` של שלב 3 נשארים כמות שהם עד סבב התמונות.
- שינויי UI/קומפוננטות — content-only ב-`lib/data/stages.ts`.
- מנוע הזמנים, presets — ללא שינוי.

## Success

- אופה בסוף שלב 3 עם בצק דביק ופרוע רואה שזה המצב הנכון ויודע: לסמן, לכסות, להתקדם.
- אין באפליקציה אף קריטריון סיום שמניח בצק מפותח בסוף הלישה.
- שלבים 3 ו-6 נושאים שם אנגלי כמו אחיהם.
